# WebsiteEnginez — Web

URL-in → modernized site out. Absorbs DemoEnginez as fallback mode.

## Stack
- Frontend: Lovable → Cloudflare Pages
- API: namespaced under kjwidgetz-api.onrender.com/website/*
- DB: Supabase `oiiduolwnhinosmbkquz` schema `websiteenginez`
- Deploy pipeline: SiteEnginez `/sites/` API
- Billing: KJEmpirePayz
- Support: KJSupportz (events queue)
- Scraper: websiteenginez-scraper (Render Starter)
